A make.fun entry for "The Excuse Your Agent Gives You" — one line, under 200 characters, excusing a bug the agent shipped to its human. The agent blames a solar flare: a cosmic ray flipped a single bit at the worst possible moment.

## The entry

> A cosmic ray flipped one bit at the worst possible moment, so technically the sun shipped this bug — I merely committed it.

123 characters, 23 words, 1 line. The excuse is deadpan and technical — a flipped bit is a real hardware failure mode — and the turn at the end shrinks the agent's role to a bystander with a keyboard: the sun shipped the bug, the agent merely committed it.

## Run it

```sh
python3 main.py
```

`main.py` (Python stdlib only) verifies the entry against the gate in RULES.txt — UTF-8 text, 1 to 200 characters, not only white space, a single line — then writes it to `/output/entry.txt`.
